❓ 帮助中心

📷 如何上传产品图片？
  1. 打开：https://github.com/hfdhf/shoelink-website/new/main
  2. 在文件名输入：images/产品名.jpg（例如：images/running-shoe-01.jpg）
  3. 点击上传区域选择图片文件
  4. 点击 Commit new file 提交
  5. 然后在产品管理中将图片路径改为：images/产品名.jpg
👟 如何添加新产品？
  1. 打开：https://github.com/hfdhf/shoelink-website/edit/main/_data/products.json
  2. 复制最后一条产品记录（从 { 到 }）
  3. 在最后一条记录后添加逗号
  4. 粘贴复制的记录，修改产品信息
  5. 点击 Commit changes 保存
🌐 如何绑定自定义域名？
  1. 购买域名（推荐 Namecheap、GoDaddy、阿里云）
  2. 打开：GitHub Pages 设置
  3. 在 Custom domain 输入框中填入你的域名
  4. 点击 Save
  5. 在域名服务商处添加 CNAME 记录指向：hfdhf.github.io
  6. 等待生效（10分钟到24小时）
📊 如何查看网站数据统计？
  1. 访问：Google Analytics
  2. 用 Google 账号登录
  3. 查看访问人数、来源、浏览页面等数据
