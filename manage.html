❓ 帮助中心

📷 上传产品图片
  1. 打开：github.com/hfdhf/shoelink-website/new/main
  2. 文件名输入：images/产品名.jpg
  3. 点击上传区域选择图片
  4. 点击 Commit new file
  5. 在产品管理中修改图片路径为 images/产品名.jpg
👟 添加新产品
  1. 打开：编辑 products.json
  2. 复制最后一条产品记录
  3. 添加逗号后粘贴，修改内容
  4. 保存
🌐 绑定域名
  1. 购买域名
  2. 打开：GitHub Pages 设置
  3. Custom domain 填入域名，保存
  4. 域名服务商处添加 CNAME 指向 hfdhf.github.io
