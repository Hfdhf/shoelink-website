📖 使用说明
  1. 在下方各标签页中修改内容
  2. 修改后点击 "生成代码" 按钮
  3. 点击 "复制代码" 按钮
  4. 点击 "打开 GitHub 文件"，粘贴代码并保存
  5. 等待 1-2 分钟，网站自动更新

⚠️ 必须复制代码粘贴到 GitHub 对应文件才能生效。

❓ 帮助

📷 上传图片
  1. 打开：github.com/hfdhf/shoelink-website/new/main
  2. 文件名输入：images/图片名.jpg（如 images/men-shoe-01.jpg）
  3. 点击上传区域选择图片
  4. 点击 Commit new file
  5. 在后台对应位置填写路径：images/图片名.jpg
